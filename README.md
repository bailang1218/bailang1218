# Hi, I'm whitewolf / 白狼

我在做 Windows 桌面 AI 工具，关注 Agent 运行时、浏览器自动化，以及让开源工具更容易安装和使用。

I build desktop AI tools, with a focus on agent runtimes, browser automation, and practical Windows distribution.

## Projects

### [PawMate AI](https://github.com/bailang1218/pawmate-ai)

带动画桌宠的 Windows 本地 AI Agent，使用 Python / PySide6，包含 ReAct 与 Plan-and-Execute 运行时、多模型路由、浏览器工具和长期记忆。

- 工作重点：运行时集成、工具执行与取消、记忆、桌面交互和回归测试。
- 当前状态：公开源码 Alpha；需要自行配置模型 API key。
- [截图与运行说明](https://github.com/bailang1218/pawmate-ai#readme) · [测试记录](https://github.com/bailang1218/pawmate-ai/actions)

### [DeepSeek Harness Desktop](https://github.com/bailang1218/deepseek-harness-desktop)

基于上游 DeepSeek Harness 的社区桌面发行版，使用 Tauri 提供桌面载体和安装包。

- 我维护的部分：桌面集成、运行时打包、安装与启动体验，以及平台适配。
- Harness 核心来自 [DeepSeek 上游](https://github.com/deepseek-ai/deepseek-harness)；本项目不是官方签名发行版。
- [下载安装包](https://github.com/bailang1218/deepseek-harness-desktop/releases) · [平台状态与使用说明](https://github.com/bailang1218/deepseek-harness-desktop#readme)
